FullFileStudio First Public Release
First open beta release of FullFileStudio! Features hardware-accelerated OpenGL ES 3.0 Z-Buffer 3D rendering (GLSL 3.00 ES shaders), 40+ supported formats (STEP, IGES, STL, OBJ, DXF, DWG, 3MF, DAE, PLY, OFF, 3DS, GLTF, GLB, BLEND, USDZ, FBX, PDF, DjVu, DOCX, XLSX, PPTX, EPUB, FB2, MOBI, ZIP, 7Z, ISO, HEX), on-device neural PaddleOCR, Predictive Back Gestures (Android 11–16+), and zero-copy Linux SharedMemory process isolation.
