Privacy Policy for FullFileStudio

Effective Date: November 22, 2026

FullFileStudio is developed by Hleb Kukleuski as an open-source, privacy-first mobile file reader. This Privacy Policy accurately describes how the application handles your data and Android permissions.

1. Zero Data Collection & 100% Local Processing

All document rendering, archive extraction, 3D/CAD viewing, database inspection, media playback, and neural OCR text recognition execute 100% locally on your device inside an isolated Android sandbox process. FullFileStudio does not collect, transmit, store, profile, or sell any personal data, files, crash logs, analytics, or telemetry. No advertising or tracking SDKs are included in any build.

2. Android Permissions

FullFileStudio requests only the minimum system permissions required for its local features:

  • File access: Handled exclusively via Android's Storage Access Framework (SAF) and explicit user file picks; no broad storage permissions are requested.
  • POST_NOTIFICATIONS, FOREGROUND_SERVICE, FOREGROUND_SERVICE_MEDIA_PLAYBACK, WAKE_LOCK: Used solely to display media playback controls and keep audio/video playing smoothly when the user plays a local media file.
  • Google Play build (googlePlay): Requests zero network permissions (no INTERNET and no ACCESS_NETWORK_STATE). All format engines are bundled inside the app and it cannot initiate network connections.
  • Standalone GitHub build (standalone only): Requests INTERNET, ACCESS_NETWORK_STATE, and REQUEST_INSTALL_PACKAGES strictly for optional HTTPS (TLS 1.3) release update checks against hlebkukleuski.github.io/FullFileStudio/version.json and user-confirmed APK downloads from GitHub Releases. Standard HTTP metadata (such as your IP address and user-agent) is handled by GitHub's servers solely when fetching that update manifest or APK.

3. Third-Party Services & Embedded WebView Sandbox

FullFileStudio includes no proprietary analytics, crash-reporting, or Google Play Services SDKs. When rendering local HTML/MHTML files in the built-in viewer, all external network requests are blocked by an offline WebView sandbox.
